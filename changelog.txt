Version: 0.3.1
Date: 2026-11-13
  Bugfixes:
    - When starting on Zzhora, Agriculture and Heating tower no longer require "Planet discovery Gleba" (this locked out the biochamber and so the only calcite source). Their stromatolite mining triggers still apply.
  Compatibility:
    - Autoplace controls inherited from Gleba that another mod has removed (for example "gleba_stone" with Angel's mods) are dropped instead of failing the load.

Version: 0.3.0
Date: 2026-11-12
  Changes:
    - Any Planet Start is now an optional dependency. The start-planet choice and the tech tree changes only apply when it is installed and this planet is the chosen start planet.
  Bugfixes:
    - Fixed tech tree changes (hiding or re-wiring vanilla technologies) being applied whenever the mod was enabled instead of only when starting on this planet.
  Balancing:
    - The Biocalcite recipe can now only be crafted on Zzhora.
